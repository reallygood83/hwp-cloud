    설치 없이 바로

    Aside 브라우저에서 이 페이지를 열고 문서를 연 뒤, Aside에게 이렇게 말하세요.

    • 오른쪽 Aside 도구를 보고 이 문서를 요약해줘
    • 표 1의 빈칸을 채워줘. 성명은 홍길동, 소속은 교무부
    • 문서 전체에서 2025년을 2026년으로 바꿔줘

    스킬로 추가하면 더 정확합니다 (1분)

    1. Aside 앱에서 Settings → Plugins & MCPs → My Skills로 가서 Create new skill을 누릅니다.
    2. 아래 값을 칸마다 복사해 붙여넣습니다.
      Name
      hwp-cloud
      Description
      HWP Cloud에서 한글(HWP) 문서를 읽거나 고칠 때 먼저 읽는다
      Instructions
      사용 설명서 전체
      Activation → Websites
    3. 저장하면 끝입니다. 다음부터 이 사이트를 열면 Aside가 스킬을 알아서 씁니다.

    폴더로 가져오고 싶으면 SKILL.md 내려받기 후 새 폴더에 넣고 Import skill folder를 누르세요.
